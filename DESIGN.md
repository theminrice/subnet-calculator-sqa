# DESIGN.md

Gaya: bersih, minimalis, mode terang, ala Google.

- Latar halaman: #f8f9fa. Kartu: putih, border #dadce0, sudut 16px.
- Teks: #202124. Teks sekunder: #5f6368.
- Aksen biru: #1a73e8 (tombol utama, tab aktif, fokus). Galat: #c5221f.
- Font: Google Sans, lalu Segoe UI dan system-ui. Angka hasil memakai font monospace.
- Tata letak: satu kolom, lebar maksimal 760px, dua tab (Subnet dan VLSM).
- Tiga keadaan: kosong (petunjuk singkat), sukses (kartu hasil atau tabel), galat (pesan merah di bawah kolom).
- Responsif: kolom input membungkus di layar sempit; tabel VLSM menggulir di dalam kartunya.
